P043 [Normal]: ABSTRACT
P044 [Normal]: In smallholder dairy farming, precision livestock health monitoring is often constrained by the high cost of specialized RFID readers, proprietary wearable sensors, and rigid population-wide thresholds. These conventional approaches frequently trigger false alarms by failing to account for individual cattle physiological variations and sparse field data.
P045 [Normal]: To address this challenge, this project presents a QR-Based Cattle Management System, an infrastructure-light, cloud-based platform for personalized dairy health monitoring using the Composite Health Deviation Index (CHDI). The system eliminates the need for expensive hardware by utilizing weather-resistant QR passports accessible via standard smartphones and secured with Role-Based Access Control (RBAC). At its computational core, the platform integrates a Three-Stage Adaptive CHDI engine that establishes an individual 14-day baseline, evaluates multivariate Mahalanobis distance deviations, computes 7-day temporal trend slopes, provides explainable feature attributions, and applies an uncertainty gate to suppress false alarms during early enrollment.
P046 [Normal]: The application is implemented as a full-stack solution using Next.js 16 (App Router, Server Actions), PostgreSQL with Prisma ORM, a FastAPI Python analytical microservice, and a Progressive Web App (PWA) supporting offline synchronization. System evaluation demonstrates 90.48% sensitivity, 96.27% specificity, 62.30% precision, and an F1-score of 73.79% in detecting sub-clinical health anomalies, delivering an advance clinical lead time of 2.4 days prior to observable symptoms.

P057 [Normal]: 1. INTRODUCTION
P058 [Normal]: 1.1 Background of the Project
P059 [Normal]: In global livestock agriculture and rural economies, smallholder dairy farming represents a vital socio-economic backbone for over 150 million rural farming households. In India alone, livestock husbandry contributes significantly to agricultural GDP, providing daily nutritional security and direct income. Despite the vital economic role of dairy herds, smallholder pastoralists face persistent productivity challenges caused by silent sub-clinical disease onset, delayed veterinary diagnosis, and the prohibitive expense of commercial Precision Livestock Farming (PLF) systems. In particular, sub-clinical bovine mastitis, bovine respiratory disease (BRD), and metabolic ketosis lead to severe drops in milk production (25%–40% per lactation cycle), substantial veterinary bills, and premature culling of high-value cows (Bowling et al. 2008; Kamphuis et al. 2010).
P060 [Normal]: While modern electronic identification and wearable biosensors have been investigated extensively, commercial systems depend on costly proprietary RFID tags, specialized reading wands, and expensive wearable sensor collars. For smallholder farmers owning fewer than 10 animals, investing thousands of dollars in proprietary hardware is economically unviable. Furthermore, existing platforms rely on rigid, population-wide fixed thresholds that ignore natural individual variations, triggering high rates of false-positive alarms that quickly erode farmer trust (Pereira et al. 2024; Kaur & Virk 2024). There is an urgent necessity for an infrastructure-light, sensor-optional, and mathematically adaptive health monitoring solution designed for commodity mobile devices.
P061 [Normal]: 1.2 Problem Statement
P062 [Normal]: Smallholder dairy farmers and rural veterinary officers often lack affordable, accessible, and reliable digital tools for livestock health monitoring. Existing precision livestock systems face three major operational and economic challenges:
P063 [Normal]: 1. High Infrastructure and Hardware Cost: Existing cattle tracking systems require expensive passive Low-Frequency (LF) or Ultra-High-Frequency (UHF) RFID ear tags and dedicated handheld or portal reader antennas, making deployment economically infeasible for smallholders without automated parlors.
2. Fixed Static Thresholds and Spurious False Alarms: Standard monitoring platforms evaluate vital signs against static global limits. Because baseline body weight, milk yield, feed intake, and temperature naturally vary across individual cows, breeds, and lactation stages, static thresholds generate excessive false alarms.
3. Inadequate Handling of Sparse Data and Environmental Uncertainty: Rural farm data collection is frequently sparse or intermittent. Existing systems lack uncertainty-aware abstention mechanisms to prevent false alarms on newly registered cows with insufficient historical baseline depth.
P064 [Normal]: 1.3 Motivation
P065 [Normal]: The primary motivation of this project is to democratize precision livestock health intelligence for smallholder dairy farmers by developing an infrastructure-light, cloud-native software platform. By replacing expensive proprietary hardware with weather-resistant, smartphone-scannable QR digital passports and substituting rigid thresholds with a personalized, Three-Stage Composite Health Deviation Index (CHDI) engine, the proposed system provides early clinical warning, explainable diagnostic attributions, and automated veterinary triage at zero specialized hardware cost (Subach & Shmeleva 2024; Curti et al. 2024).

P074 [Normal]: 2.2 Review of Related Studies
P075 [Normal]: Bowling et al. (2008) presented an international review of national livestock traceability systems across the EU, Australia, and Japan. Their study demonstrated that lifetime traceability databases are essential for controlling epidemic disease outbreaks, but noted that passive RFID transponders incur high infrastructure expenses, reader hardware dependencies, and ear-tag retention loss.
P076 [Normal]: Pereira et al. (2024) conducted a comprehensive literature and patent analysis on passive UHF RFID animal tracking. While UHF RFID offers non-line-of-sight reading ranges in industrial feedlots, the substantial capital expenditure of fixed reader portals and specialized hand scanners makes the technology inaccessible to smallholder farmers with small herds.
P077 [Normal]: Bumbálek et al. (2024) performed a comparative study using YOLOv8 for cattle body-texture biometric identification, numerical ear-tag OCR, and optical QR collars. Their results showed that QR tags offer instant identification without requiring complex deep convolutional neural network retraining for each new animal, although optical approaches require weather-resistant tags and manual fallback workflows.
P078 [Normal]: Subach & Shmeleva (2024) investigated the adoption of digital technologies in dairy farming, emphasizing that software simplicity, low capital requirements, and mobile accessibility are the primary determinants of technology adoption among small-scale agrarian producers.
P079 [Normal]: Kaur & Virk (2024) developed an IoT-based smart neck collar integrating 3-axis accelerometers, digital thermometers, and pulse sensors for real-time disease detection in 150 dairy cows. Their Random Forest and Decision Tree models achieved 92% and 91% accuracy for mastitis and BRD, but they noted major operational limitations including high sensor replacement costs, battery degradation, and physical damage from social grooming.
P080 [Normal]: Curti et al. (2024) evaluated machine learning approaches for individual livestock health records, demonstrating that multi-parametric covariance modeling provides superior anomaly sensitivity over univariate threshold rules.
P081 [Normal]: Aquilani et al. (2022) surveyed precision livestock farming technologies for pasture-based ruminants, reviewing walk-over weigh scales, GPS collars, and thermal imaging. They emphasized that multi-signal telemetry is essential for accurate health evaluation, but noted that high maintenance costs remain a persistent barrier.
P082 [Normal]: Ahmad & Salamat (2023) developed a web-based veterinary clinic management system, demonstrating the necessity of structured digital medical histories, vaccination scheduling, and role-based access control for clinical workflows.
P083 [Normal]: Barriuso et al. (2018) presented a multi-agent Wireless Sensor Network (WSN) using MQTT messaging for pasture cattle monitoring, validating the effectiveness of asynchronous message queuing for agricultural sensor data dispatch.
P084 [Normal]: Hostens et al. (2024) published a comprehensive longitudinal multimodal dataset on Zenodo covering daily milk yield, feeding intake, and body weight metrics for dairy cows, establishing standardized benchmark reference distributions for precision health algorithms.
P085 [Normal]: Jensen & Bennedsen (2023) published high-resolution accelerometer time-series telemetry in lactating cows, demonstrating that rumination and movement drop significantly 48–72 hours prior to acute clinical symptoms of infectious bovine mastitis.
P086 [Normal]: Kamphuis et al. (2010) analyzed automated mastitis detection using decision trees and proved that combining electrical conductivity with historical longitudinal deviation scores substantially reduces false alarm rates compared to static population thresholds.
P087 [Normal]: Kim et al. (2024) curated the 'MmCows' multimodal dairy cattle dataset, demonstrating that cross-variable physiological coupling enables early sub-clinical anomaly detection in commercial herds.
P088 [Normal]: Ankitha, Manjaiah & Kartik (2024) evaluated udder surface temperature variations in clinical mastitis, showing that localized inflammatory fever precedes systemic thermal spikes by 2 to 3 days.
P089 [Normal]: 2.3 Techniques and Technologies Used in Existing Systems
P090 [Normal]: Existing precision livestock management systems predominantly employ three technological categories:
1. Passive LF/UHF RFID Identification: Electronic ear tags requiring specialized handheld readers or portal antennas costing thousands of dollars.
2. Proprietary Sensor Collars & Boluses: Battery-powered edge IoT devices transmitting raw accelerometer and thermistor readings via proprietary base stations.
3. Static Rule-Based Threshold Software: Monolithic farm software evaluating single vitals against fixed population thresholds (e.g., temperature > 39.5°C).
P091 [Normal]: 2.4 Research Gap
P092 [Normal]: Despite extensive research, four critical gaps remain unaddressed in precision dairy management:
1. Heavy Infrastructure Dependency: Existing systems require specialized electronic RFID readers or mandatory wearable hardware, leaving smallholders excluded.
2. Rigid Static Thresholds: Current commercial systems ignore individual baseline variance, causing high false alarm rates during heat waves or normal diurnal fluctuations.
3. Lack of Explainability & Uncertainty Gates: Existing algorithms output black-box alerts without explaining which physiological signals caused the alarm, and lack safeguards to prevent false alarms on newly registered cows with sparse history.
4. Absence of Closed-Loop Veterinary Feedback: No existing platform connects automated anomaly detection with clinical veterinary triage and prescription drug withdrawal tracking.

P096 [Normal]: 3. CHAPTER 1 – NEED FOR PROPOSED TECHNIQUE
P097 [Normal]: 3.1 Existing Techniques
P098 [Normal]: Conventional livestock health management in smallholder dairy farming relies primarily on visual manual observation by farmers (e.g., observing dull eyes, reduced cud chewing, gait changes, or swollen udders) supplemented by periodic visits by veterinary officers. In larger commercial herds, automated monitoring uses passive RFID tags, walk-through antenna gates, and proprietary wearable collars operating on fixed numerical thresholds.
P099 [Normal]: 3.2 Limitations of Existing Techniques
P100 [Normal]: The limitations of existing techniques are profound and directly harm smallholder productivity:
1. Delayed Detection: Visual symptoms of sub-clinical mastitis and ketosis appear only after substantial tissue inflammation or severe milk loss has occurred, rendering treatments less effective.
2. Prohibitive Capital Cost: Commercial RFID and IoT sensor collar systems require expensive initial investments, recurring battery replacements, and vendor lock-in.
3. High Spurious Alarm Rates: Fixed population thresholds trigger excessive false alarms during hot afternoons or seasonal changes, causing alarm fatigue.
4. Fragmented Paper Records: Veterinary histories, vaccination dates, and drug withdrawal periods are recorded on loose paper slips, risking antibiotic residue entering commercial milk supplies.
P101 [Normal]: 3.3 Proposed Technique
P102 [Normal]: The proposed technique introduces 'SmartCattle' (QR-Cattle-Health)—an infrastructure-light, sensor-optional, cloud-native dairy health management system. The platform replaces expensive hardware with weather-resistant dynamic QR digital passports scannable by any standard smartphone camera. Daily multi-signal health logs (body weight, feed intake, milk yield, temperature, and activity) are evaluated by an adaptive Three-Stage Composite Health Deviation Index (CHDI) engine. CHDI tracks personalized 14-day rolling baselines, calculates multivariate Mahalanobis distance anomalies across empirical signal covariances, evaluates 7-day temporal slope trajectories, decomposes feature attributions, and enforces an uncertainty gate ($N_{min}=7$) to safely suppress false alarms.
P103 [Normal]: 3.4 Objectives of the Proposed Technique
P104 [Normal]: The key objectives of the proposed technique are:
1. Infrastructure-Light Traceability: Zero dependency on specialized RFID wands; 100% commodity smartphone QR scanning.
2. Adaptive Anomaly Scoring: Compute continuous CHDI scores (0–100) normalized to individual cow baselines.
3. 2.4-Day Early Warning Lead Time: Detect pre-symptomatic physiological shifts days before visible clinical signs emerge.
4. Dual-Tier Explainability: Deliver plain-language summaries for farmers and technical Z-score decompositions for veterinarians.
5. Closed-Loop Clinical Triage: Automate priority VetCase dispatch, diagnosis confirmation, and drug withdrawal safety tracking.
P105 [Normal]: 3.5 Advantages of the Proposed Technique
P106 [Normal]: The proposed technique offers distinct operational, clinical, and economic advantages:
• Near-Zero Hardware Cost: Relies on printable QR tags and mobile web browsers already owned by farmers.

• Milk Biosecurity: Integrated withdrawal tracking prevents antibiotic residue contamination in commercial dairy supplies.
• Robust Offline Operation: PWA architecture with IndexedDB ensures seamless data recording in remote rural barns.

P146 [Normal]: 4.7 Algorithms/Techniques Used
P147 [Normal]: The mathematical foundation of SmartCattle executes across three analytical stages as formalized in Section IV of the IEEE paper:

Stage 1: Individual Rolling Baseline & Standardized Deviations:
For each physiological parameter $k \in \{1, 2, \dots, 5\}$ of animal $i$, the 14-day rolling mean $\mu_{i,k}$ and variance $\sigma_{i,k}^2$ are computed:
    $\mu_{i,k} = \frac{1}{|W|} \sum_{t \in W} x_{i,k}(t)$
    $\sigma_{i,k}^2 = \frac{1}{|W| - 1} \sum_{t \in W} (x_{i,k}(t) - \mu_{i,k})^2$
The standardized individual deviation (Z-score) is calculated as:
    $z_{i,k} = \frac{x_{i,k} - \mu_{i,k}}{\sigma_{i,k} + \epsilon}$

Stage 2: Multivariate Covariance & Mahalanobis CHDI Formulation:
Let $z_i = [z_{i,1}, z_{i,2}, \dots, z_{i,5}]^T$ be the normalized deviation vector and $\Sigma$ be the $5 \times 5$ empirical covariance matrix. The multivariate Mahalanobis distance $D_M(z_i)$ is:
    $D_M(z_i) = \sqrt{z_i^T \Sigma^{-1} z_i}$
To provide an intuitive score, raw distance is scaled to a bounded Composite Health Deviation Index (CHDI) on a 0–100 scale:
    $CHDI(z_i) = 100 \times \exp(-\lambda D_M(z_i))$
where $\lambda = 0.35$ is the exponential scaling decay factor. Table 4.3 defines the resulting clinical severity bands.
P148 [Normal]: Table 4.3: CHDI Severity Bands, Distance Thresholds, and Clinical Protocols
P149 [Normal]: Stage 3: Temporal Trend, Explainability, and Uncertainty Estimation:
1. 7-Day Trend Slope: Computed via OLS linear regression across the last $k=7$ observations:
    $S = \frac{\sum_{t=1}^k (t - \bar{t})(CHDI_t - \overline{CHDI})}{\sum_{t=1}^k (t - \bar{t})^2}$
2. Permutation Feature Attribution: Quantifies the percentage contribution $C_k$ of variable $k$:
    $C_k = \frac{D_M(z) - D_M(z_{-k})}{\sum_{j=1}^m (D_M(z) - D_M(z_{-j}))} \times 100\%$
3. Data-Sufficiency Uncertainty Gate: Prevents false alarms on new animals with sparse logging history:
    $Conf(N) = \min\left(1.0, \frac{N}{N_{min}}\right), \quad N_{min} = 7$

P155 [Normal]: 4.9 Data Preprocessing
P156 [Normal]: Raw field logs undergo standard validation and preprocessing:
1. Range Verification: Biologically implausible values (e.g., negative milk yield or body temperature > 45°C) are rejected at form entry.
2. 14-Day Rolling Window Isolation: For each cow, observations within the last 14 days ($|W| = 14$) are extracted to update baseline statistics.
3. Regularized Inversion: Tikhonov ridge regularization ($\lambda_{reg} = 10^{-3}$) is applied to covariance matrix $\Sigma$ to prevent singularity under collinear telemetry.

from scipy.spatial.distance import mahalanobis
from typing import List, Dict, Tuple

# Mathematical Constants from IEEE Paper Section IV
DEFAULT_WINDOW_SIZE = 14          # W = 14 observations baseline window
TIKHONOV_LAMBDA = 1e-3            # Ridge regularization parameter
D_MAX = 4.0                       # Maximum distance boundary
N_SATURATION = 14                 # Baseline saturation threshold

def calculate_chdi_score(obs: List[float], history: List[List[float]]) -> Dict:
    """Three-Stage CHDI computation across multi-signal history."""
    X = np.array(history)
    n_obs, n_features = X.shape
    
    # Stage 1: Individual 14-day rolling baseline
    mu = np.mean(X, axis=0)
    sigma = np.std(X, axis=0, ddof=1) + 1e-4
    z = (np.array(obs) - mu) / sigma
    
    # Stage 2: Empirical Covariance and Mahalanobis Distance
    cov = np.cov(X, rowvar=False) + TIKHONOV_LAMBDA * np.eye(n_features)
    inv_cov = np.linalg.pinv(cov)
    d_m = float(mahalanobis(z, np.zeros_like(z), inv_cov))
    
    # Bounded CHDI mapping: 0 to 100
    chdi = round(float(100.0 * np.exp(-0.35 * d_m)), 2)
    status = 'HEALTHY' if chdi >= 80 else ('WATCH' if chdi >= 60 else ('WARNING' if chdi >= 40 else 'CRITICAL'))
    
    # Stage 3: Data-sufficiency uncertainty gate
    conf = min(1.0, n_obs / 7.0)
    return {'chdi': chdi, 'status': status, 'd_m': round(d_m, 3), 'confidence': round(conf, 2)}

import { prisma } from '@/lib/prisma';

export async function GET(req: NextRequest, { params }: { params: { token: string } }) {
  try {
    const { token } = params;
    // Resolve cattle digital passport by cryptographic token
    const cattle = await prisma.cattle.findUnique({
      where: { qrToken: token },
      include: {
        farmer: { select: { name: true, phone: true } },
        healthRecords: { take: 14, orderBy: { recordedAt: 'desc' } },
        prescriptions: { where: { active: true } }
      }
    });
    if (!cattle) return NextResponse.json({ error: 'Cattle not found' }, { status: 404 });
    return NextResponse.json({ success: true, cattle });
  } catch (error: any) {
    return NextResponse.json({ error: error.message }, { status: 500 });
  }
}

P196 [Normal]: 5.3 Evaluation Metrics
P197 [Normal]: System evaluation follows standard statistical metrics:
• Sensitivity (Recall): $\frac{TP}{TP + FN}$, measuring the proportion of true clinical anomalies detected.
• Specificity: $\frac{TN}{TN + FP}$, measuring resistance against false alarms on healthy baseline days.
• Precision: $\frac{TP}{TP + FP}$, proportion of generated alerts corresponding to genuine clinical distress.
• F1-Score: Harmonic mean of precision and sensitivity: $2 \times \frac{Precision \times Sensitivity}{Precision + Sensitivity}$.
• Diagnostic Lead Time: Advance warning time (in days) between first sub-clinical CHDI alert and observable clinical symptoms.

P219 [Normal]: The SmartCattle project engineered an infrastructure-light, cloud-native livestock health management system.
