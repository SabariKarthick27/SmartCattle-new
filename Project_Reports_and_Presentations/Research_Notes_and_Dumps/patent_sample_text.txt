g. Provide a general overview of your invention, including specific keywords and phrases pertaining to the 
invention: [Briefly provide the basic understanding of the invention and also point out specific keywords.] 
 The present invention relates to an AI-driven examination security system designed to eliminate proxy    candidates 
and ensure real-time identity verification inside physical examination halls. The system utilizes multi-camera video 
input, deep-learning-based facial recognition , liveness/anti-spoofing detection , and continuous behavioural 
monitoring to verify that the same registered candidate remains seated throughout the exam. The invention 
automatically matches live facial data with the pre -registered candidate database and seat -map records, detects 
impersonation attempts, identifies face-hiding or seat-swapping behaviour, and generates immediate alerts to invigilators 
through a centralized dashboard. The invention enhances exam integrity by providing full-duration, automated, non-
intrusive identity consistency tracking along with secure audit logs and evidence reports.

1. Continuous, Full-Duration Identity Verification 
Prior systems verify identity only once at the entry gate. 
The invention performs continuous real-time facial verification throughout the entire exam, preventing mid-exam 
impersonation — a major limitation in earlier technologies. 
2. Automated Proxy Detection With Real-Time Alerts 
Existing CCTV or biometric systems do not detect proxy candidates automatically. 
The invention provides instant alerts for identity mismatch, face hiding, seat swapping, or unrecognized individuals, 
enabling immediate corrective action. 
3. Multi-Camera Identity Consistency Across the Hall 
Traditional systems operate at a single point of capture. 
The invention integrates and synchronizes multiple camera streams, ensuring accurate face tracking from different 
angles and preventing candidates from avoiding detection. 
4. Direct Integration With Candidate Database and Seating Plan 
Prior art does not combine live video analysis with candidate registration records. 
The invention uniquely performs live face-to-database matching and seat-map verification, enabling accurate, 
automated identity validation for each candidate. 
5. Reduction of Human Error and Enhanced Security 
Manual invigilation is highly prone to oversight and manipulation. 
The invention automates identification, behavioural monitoring, and alert generation, resulting in a more reliable, 
scalable, and tamper-resistant examination environment.

       i.Provide a detailed explanation of your invention: [Specifically describe all the element and components of the 
invention. Also describe how all the elements and components work together to form the invention. For more clarity and 
understanding, respective examples, diagrams, flowcharts, etc. may be provided] 
1. Candidate Enrollment and Database Module 
This module collects and stores all pre-exam identity data. 
Components: 
Candidate photograph capture 
• Candidate personal and examination details 
• Seating plan and hall allocation 
• Secure, encrypted identity database 
Function: 
Before the examination begins, each candidate’s facial image and identity information are registered in the system. This 
data forms the basis for real-time matching during the exam. 
 
2. Multi-Camera Capture System 
This component captures continuous video streams of all candidates in the examination hall. 
Components: 
• Multiple CCTV/AI cameras positioned across the hall 
• Network video streaming unit 
• Camera synchronization controller 
Function: 
All cameras simultaneously record video of the hall from different angles. This ensures that each candidate’s face remains 
visible and trackable during the exam. 
 
3. AI Face Processing and Verification Module 
This module performs real-time biometric analysis on incoming video frames. 
Components: 
• Face detection algorithm 
• Facial recognition engine 
• Liveness and anti-spoofing detector 
• Face embedding generator 
Function: 
The system determines whether: 
1. The detected face is real (not a photo/video/mask). 
2. The face matches the registered candidate profile. 
3. The same verified face remains present throughout the exam.

4. Behavioural and Consistency Analysis Module 
This module ensures that the candidate’s identity remains consistent and that no suspicious activity occurs. 
Components: 
• Multi-object tracking algorithms 
• Head/face orientation analysis 
• Seat-position verification 
• Behaviour monitoring engine 
Function: 
This module detects: 
• Face hiding or obstruction 
• Seat swapping 
• Temporary absence from seat 
• Appearance of an unknown face 
• Multiple faces appearing at a single seat 
 
5. Identity Matching and Verification Module 
This component compares real-time face embeddings with the registered database. 
Components: 
• Face embedding comparator 
• Seating plan validator 
• Identity confidence scoring engine 
• Decision system 
Function: 
If the system detects a mismatch, unknown face, or any identity inconsistency, it triggers a real-time alert for invigilators. 
 
6. Real-Time Alert and Notification System 
This system provides immediate warnings when abnormal or prohibited behaviour occurs. 
Components: 
• Red alert (proxy/mismatch) 
• Yellow alert (face hiding or abnormal movement) 
• Blue alert (absence from seat) 
• Notification delivery engine 
Function: 
Alerts are displayed instantly on the invigilator’s dashboard and can also be sent via SMS, email, or mobile notifications.

• API gateway 
• Load balancer 
• Security layer (RBAC, encryption, privacy management)

Ensures fast processing, secure data handling, system scalability, and integration with institutional platforms. 
 
10. End-to-End Operational Flow 
1. Candidates are enrolled and assigned seats. 
2. Multi-camera system captures live examination footage. 
3. AI detects and verifies each candidate’s face continuously. 
4. Liveness and behavioural checks run simultaneously. 
5. Any identity mismatch or suspicious activity triggers alerts. 
6. Invigilators monitor live alerts via dashboard. 
7. All activities are logged and stored as evidence.
